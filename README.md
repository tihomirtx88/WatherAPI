# 🌦 Weather Data Lookup (Flask + Pandas)

A simple Flask web application for exploring historical weather temperature data by **station number** and **date**.  
The app allows you to:
- View all available weather stations with their names.
- Search for the temperature on a **specific date** for a given station.
- View **all temperatures** for all available dates when only the station is provided.

---

## ✨ Features
- **Station lookup** — browse all stations in a table.
- **Date-specific temperature search** — enter a station number and a date (YYYY-MM-DD) to get the temperature for that day.
- **Full station history** — enter only a station number to see all recorded temperatures for that station.
- **Clean HTML interface** — simple, responsive, and functional UI.
- **CSV-based data loading** — reads directly from text/CSV files.
